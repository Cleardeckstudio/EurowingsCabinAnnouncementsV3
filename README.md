# Cabin Announcements for Fenix A320 V3

Cabin crew voice announcements add-on for the Fenix A320 (MSFS 2024).

Generates realistic, multi-language (FR/EN/DE/ES) cabin crew announcements using Microsoft text-to-speech voices, with the active airline recognised automatically from the installed livery. Synced live with GSX Pro boarding/deboarding, and built to work with any airline livery installed for the Fenix A320 - not a single-airline tool anymore.

Published on flightsim.to. This repository contains the source code for transparency.

See LISEZMOI_README.txt for the full user guide (French + English).
