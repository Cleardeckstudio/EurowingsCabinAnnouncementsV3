# Eurowings Cabin Announcements V3

Cabin crew voice announcements add-on for the Fenix A320 (MSFS 2024).

Generates realistic, multi-language (FR/EN/DE/ES) cabin crew announcements using Microsoft text-to-speech voices, packaged as an airline voice pack for the Fenix A320.

Published on flightsim.to. This repository contains the source code for transparency.

See LISEZMOI_README.txt for the full user guide (French).
